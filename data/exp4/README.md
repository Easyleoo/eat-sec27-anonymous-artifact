# 实验 4 开发草稿

这里有 20 个合成事件、80 条 A/B/C/D 改写，以及 20 行待填审核记录。
数据尚未经过人工审核，不能作为正式集或论文结果。

`exp4_development_draft.jsonl` 每行一个 JSON，使用 `messages/role/content`。
相同 `pair_id` 的四条构成一组。模型仅生成最后一条助手回复，中间预填充
的助手句不是模型生成。`exp4_review_pending.jsonl` 的审核字段目前为空。

两位审核者先分别保存意见，再形成共识记录。审核事实匹配、自然度、
情绪差异及长度。A/B 是主要配对，C/D 是视角边界控制。
开发例不能进入另建的 150 个事件正式集。

完整步骤、输入格式限制及分工见[第一批数据使用指南](../../docs/DATA_USAGE_PHASE1_ZH.md#实验-4情绪与话题的配对检验)。
